# 課外活動 · 完整資料站

香港中小學課外活動的完整整理：其他學習經歷（OLE）五大範疇、全方位學習及姊妹學校津貼、校內架構、一年節奏與參與公平。
純靜態網頁，零外部依賴，可直接以 GitHub Pages 發佈。

## 內容

- **三分法** — 課外活動（日常用語）／全方位學習（政策概念）／其他學習經歷（高中課程組成部分）
- **OLE 五大範疇** — 德育及公民教育、社會服務、與工作有關的經驗、藝術發展、體育發展（教育局《高中課程指引》原文範疇）
- **津貼** — 全方位學習及姊妹學校津貼；**八類活動** A1–A8（價值觀教育／智能發展／社會服務／體藝發展／與工作有關的經驗／愛國主義教育／數字教育・AI・STEAM／學生精神健康）；校董會審批＋上載網頁的問責要求
- **校內架構** — 活動主任、全方位學習負責教師、學會、校隊、服務團、學生會、社
- **一年節奏** — 9 月招生 → 10–11 月陸運會 → 1–2 月校際賽季 → 5–6 月暫停 → 7 月試後活動
- **參與公平** — 費用、時間、資訊三道門檻，以及學校可做的三件事
- **怎樣選** — 給學生的四個原則（一深兩闊、先問學到甚麼、承擔角色、留下紀錄）
- **五個爭議**、**10 條 FAQ**、**3 項限制**、**7 項來源**

## 技術與設計

`index.html` / `assets/style.css` / `assets/app.js`；無框架、無 CDN、無追蹤碼。
視覺：珊瑚橙 + 天藍 + 奶油黃，圓角卡片與時間軸步進器，呼應「活動」的輕快調性。

## 重要說明

香港沒有公開的「學生課外活動參與率」官方統計，因此本頁不提供參與百分比。
津貼金額各校不同，頁面只引用一份已公開的學校計劃作示例並清楚標明。
